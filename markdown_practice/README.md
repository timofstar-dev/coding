## 🌟 핵심 모드 및 특징

### 1. 🚀 퀘스트 학습 모드 (Interactive Quest)
- **6개 챕터 / 총 20단계**의 단계별 실습 커리큘럼:
  1. **기초 서식**: 제목(#), 굵게, 기울임, 취소선, 밑줄, 줄바꿈과 문단
  2. **목록 & 인용구**: 순서 없는 목록, 순서 있는 목록, 체크리스트, 인용구 및 중첩 인용
  3. **링크 & 미디어**: 하이퍼링크, 이미지 삽입, 링크가 걸린 이미지
  4. **코드 마스터**: 인라인 코드, 펜스 코드 블록 및 언어별 구문 강조
  5. **표(Table) & 구조화**: 수평 구분선, 표 생성, 표 정렬(:---, :---:, ---:)
  6. **고급 & 실무 확장**: 아코디언(`<details>`), GitHub 콜아웃(`> [!NOTE]`), 특수문자 이스케이프, 최종 종합 README 완성
- **실시간 유효성 검사**: 입력과 동시에 통과 조건이 실시간 체크되며, 통과 시 **축하 팡파르 사운드**와 **꽃가루(컨페티)** 효과 발생!
- **목표 비교 뷰**: 내 실시간 렌더링 화면과 정답 목표 화면을 탭으로 즉시 비교.
- **힌트 & 정답 보기**: 막힐 때 언제든 힌트와 정답 코드를 확인 및 자동 적용 가능.
- **학습 진행도 저장**: `localStorage`를 통해 완료한 레벨과 진행도가 자동 영구 저장.

### 2. ⚡ 마크다운 스피드 타자 연습 (Speed Typing)
- 마크다운 특수 기호(`*`, `#`, `[`, `]`, `(`, `)`, `` ` ``, `|`, `>`, `-`)의 타건 능력을 기르는 실전 타자 훈련.
- **5개 난이도 코스**: 기호 훈련, 체크리스트, GitHub README, 코드 블록, 데이터 테이블.
- **실시간 분석 지표**: CPM(타수), WPM(분당 단어 수), 정확도(%), 타이머.
- 실시간 타이핑 텍스트 마크다운 렌더링 화면 제공.

### 3. 🧠 마크다운 문법 퀴즈 (Grammar Quiz)
- 10개의 핵심 문법 & 헷갈리기 쉬운 함정 문제.
- 즉각적인 정답/오답 판별 및 상세한 문법 해설 제공.
- 최종 점수 및 등급 부여 (새싹 입문자부터 마크다운 마스터까지).

### 4. 🛠️ 자유 연습장 & 에디터 (Sandbox Playground)
- **풀기능 툴바**: 헤딩, 굵게, 기울임, 취소선, 인용구, 코드, 코드블록, 체크리스트, 링크, 이미지, 구분선.
- **▦ 표(Table) 자동 생성기**: 원하는 행과 열, 정렬을 지정하면 마크다운 표 뼈대를 자동 생성하여 삽입.
- **실무 템플릿 프리셋**:
  - 📌 GitHub README.md 템플릿
  - ✍️ 기술 블로그 포스팅 템플릿
  - 📋 주간 업무/스프린트 보고서 템플릿
  - 📚 CS 스터디 요약 노트 템플릿
  - 🧪 전체 문법 쇼케이스
- **실시간 통계**: 단어 수, 공백 포함/제외 글자 수, 헤딩 개수, 예상 읽기 시간.
- **내보내기 기능**:
  - `.md` 마크다운 파일 다운로드
  - 스타일이 내장된 독립 `.html` 파일 다운로드
  - 원클릭 마크다운 / HTML 클립보드 복사
- **자동 저장**: 작성 중인 내용이 로컬스토리지에 실시간 자동 보관.

### 5. 📖 원클릭 마크다운 치트시트 (Cheat Sheet Drawer)
- 우측 상단 `📖` 버튼을 누르면 언제든 열리는 슬라이드 인 치트시트.
- 원하는 문법 코드를 클릭하면 **현재 커서 위치에 즉시 삽입**!

## 🎨 디자인 및 기술 사양

- **모던 개발자 감성**: Obsidian/VSCode 스타일의 다크 모드(기본) 및 깔끔한 라이트 모드 지원.
- **웹 오디오 신시사이저 (Web Audio API)**: 외부 음원 파일 없이 순수 브라우저 오디오 API로 구현된 클릭음, 축하 멜로디, 에러 버저.
- **자체 캔버스 컨페티 엔진**: 외부 번들 없이 순수 Canvas 2D로 구동되는 부드러운 꽃가루 효과.
- **오프라인 완전 대응**: 외부 라이브러리 로드가 차단된 환경에서도 내장 정규식 파서가 동작하여 100% 정상 작동.

## 🏃‍♂️ 실행 방법

### 방법 1. 브라우저에서 바로 열기
파일 탐색기나 Finder에서 `index.html` 파일을 더블클릭하여 바로 브라우저(크롬, 사파리, 엣지 등)로 열면 즉시 실행됩니다.

```bash
# macOS 터미널에서 실행 시
open /Users/tim/안티연습/tim/markdown_practice/index.html
```

### 방법 2. 로컬 웹 서버로 실행 (추천)
```bash
cd /Users/tim/안티연습/tim/markdown_practice
python3 -m http.server 4182
# 브라우저에서 http://localhost:4182 접속
```
